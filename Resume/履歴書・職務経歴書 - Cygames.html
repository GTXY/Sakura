志望動機

貴社のフロントエンドエンジニア（東京）の募集要項を拝見し、「Webブラウザゲームの運用・開発」「Webサービスの運用・開発」「Webサイト制作」という業務内容が、私がこれまで歩んできたキャリアと強く重なると感じ、志望いたしました。私は 12 年以上にわたり Web・フロントエンド開発に携わり、近年は Vue 3 / Nuxt（Vite）/ TypeScript / Tailwind CSS / GitHub を用いた開発を行っており、貴社の開発環境と多くが共通しています。

加えて私は、幼少期のファミコンから現在の PlayStation 5・Nintendo Switch 2 まで、人生を通してゲームに親しんできた一人のユーザーです。中でも貴社の『グランブルーファンタジー』『プリンセスコネクト！Re:Dive』、家庭用機の『グランブルーファンタジー リリンク』を長年プレイし続けてきました。特に『グランブルーファンタジー』はブラウザベースのタイトルであり、私の Web・フロントエンド技術が、貴社が手がける Web ブラウザゲームづくりに直接活かせると確信しています。

貴社のミッションステートメントである「みんなでたくさんゲームをやる」に心から共感しております。一人のユーザーとして数えきれない感動を受け取ってきた立場から、今度は「チーム・サイゲームス」の一員として、世界中のユーザーへ最高の体験を届ける側に回りたいと強く願い、志望いたしました。

職務要約

2010年12月より IT 業界で働き、Web エンジニア／フロントエンドエンジニアとして 12 年以上の実務経験があります。金融、銀行、スタートアップ、O2O サービス、業務系管理システムなど、複数の現場で画面開発、UI 調整、API 結合、テスト対応を行ってきました。

キャリア初期は Java + JSP による Web 開発を担当し、その後は jQuery / Backbone.js、Vue 2 などを使ったフロントエンド開発を中心に経験してきました。蘇州銀行の案件では、2〜3 名のフロントエンドチームで要件分割・担当割り振り・工数確認・技術相談対応を行い、採用面接への参加や新メンバーへの業務説明・技術サポートも担当しました。現場では PM・UI デザイナー・バックエンド・QA と相談しながら、仕様確認から実装、結合試験まで責任を持って進めることを大切にしています。

最近は個人開発で Vue 3 / Vite / Pinia / TypeScript / Tailwind CSS や Cursor + Claude などの AI ツールを使い、プロダクトの設計・実装・運用までを一人で行っています。これまでの開発経験を活かしつつ、長年憧れてきたゲーム・エンターテインメント業界で、ユーザーに喜ばれるコンテンツづくりに丁寧に取り組んでいきたいと考えています。
