# 前端（frontend）

Vue 3 + Vite 工程。**完整项目说明、技术栈、API 与数据模型见仓库根目录 [README.md](../README.md)。**

## 常用命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发服务器（默认 <http://localhost:5173>） |
| `npm run build` | 生产构建 |
| `npm run preview` | 预览构建 |
| `npm run lint` | ESLint |
| `npm run format` | Prettier |

可选环境变量：在 `.env.local` 中设置 `VITE_API_BASE_URL`（默认 `http://localhost:8000`）。
